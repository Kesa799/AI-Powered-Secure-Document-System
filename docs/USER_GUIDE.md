# User Guide & Role Instructions

## Quick Start
1. Log in with your assigned badge number and password.
2. Select an active investigation case from the top case selection menu.
3. Use the sidebar navigation to access role-specific workflows.

## Role Specific Instructions
- **Police Officer**: Use Category Upload to file first-responder reports, incident photos, and initial statements.
- **Investigator**: Upload witness interviews, suspect profiles, and inspect the full case timeline.
- **Forensic Specialist**: Upload lab test reports, ballistics metrics, and cryptographic proofs.
- **Lawyer / Prosecutor**: Access verified evidence court packages and review blockchain verification proofs.
